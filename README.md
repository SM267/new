# DevTrack — Productivity Dashboard

A modern, responsive productivity dashboard built with **HTML, CSS, and vanilla JavaScript**.

## Features

- Add, edit, delete, and complete tasks
- Priority levels and due dates
- Search and status filtering
- Progress statistics and completion rate
- LocalStorage persistence — data survives refreshes
- Dark/light theme toggle
- Responsive layout for desktop and mobile
- No frameworks or external dependencies

## Run locally

No build step is required. Clone the repository and open `index.html` in a browser.

```bash
git clone https://github.com/SM267/new.git
cd new
```

Then open `index.html`, or serve the folder with any static web server.

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- Web Storage API

This project demonstrates DOM manipulation, event handling, form validation, array operations, filtering, responsive UI design, browser storage, and clean frontend organization without relying on a framework.
